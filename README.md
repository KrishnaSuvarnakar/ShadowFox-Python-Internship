# ShadowFox Python Internship - Task 3

## Cricket Fielding Analysis Project

This project analyzes T20 cricket fielding performance using Python and Pandas.

## Features

- Analyzes catches
- Analyzes direct hits
- Calculates runs saved
- Calculates runs conceded
- Calculates good throws
- Calculates player performance score
- Ranks players
- Creates a performance chart

## Performance Score

Performance Score =
(Catches × 10) +
(Direct Hits × 8) +
(Runs Saved × 1) +
(Good Throws × 2) -
(Runs Conceded × 2)

## Technologies

- Python
- Pandas
- Matplotlib
- CSV

```bash
pip install pandas matplotlib
